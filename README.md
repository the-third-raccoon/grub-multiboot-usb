# Windows + Linux Multiboot USB with GRUB2

This repository is a personal record of my process for setting up a Windows + Linux installation USB using GRUB2.

This is not an authoritative guide. It documents what I have tried, what worked, and any issues I encountered along the way. If you are attempting something similar, I hope that you may find these notes helpful. :)

> **Additional Notes**: 
> - This project is based on ideas and methodology presented in [uGrub](https://github.com/adi1090x/uGRUB), with added support for Windows installers.
> - This setup has only been tested in a **UEFI x64** environment with **Windows 10** and **11**. 
> - For a more robust approach to a multiboot USB, [Ventoy](https://github.com/ventoy/Ventoy) is recommended.
